## 2. 商品登録CSV（新フォーマット）要点

- 全85項目。主要列: 1=商品特定コード指定(必須)、5=カテゴリー識別コード/6=カテゴリーパス(どちらか一方)、7=商品名(新規時必須)、9=販売価格(新規時必須)、16=数量/在庫、32-33=バリエーション1/2名称、36-38=画像名、39-44=追加商品画像+説明、47=JAN、48=商品表示可否Y/N、84=商品ラベル(|区切り)
- アップロード: 管理画面 商品管理/商品一覧/アップロード・ダウンロード。項目名は全角半角・大小文字の完全一致が必要
- **文字コード: 新CSVは公式明記なし（要確認）**。旧系CSV（画像一括・カテゴリ一括登録解除・オプション一括）はS-JIS指定。カテゴリ一括登録はShift-JIS/UTF-8自動判別
- 画像一括: 画像ファイルを先に「ギガプラス10（100MBサーバー）」等へ上げ、URLをCSVに記載する方式。新CSV側の画像条件は500KB・長辺5,000pxまで

## 3. クリエイターモード（デザイン実装）要点

- Smartyテンプレート。公式タグリファレンス: `https://reference.makeshop.jp/creator-mode/`
  - 商品詳細: `$item.name` / `$item.price_html` / `$item.description` / `$item.image_S〜L` / `$item.multi_image.list[i]` / `$item.option_sku.list[i]` / `$item.is_soldout` など
  - 商品分類(一覧): `$category.name` / `$category.breadcrumb_list` / `$category.item.list[i].name/price/image_M` / `$category.pager` / 並び替えURL群
  - カートボタン出力タグの正式名は個別ページ巡回が必要（**要確認**）
- 編集可能: トップ・カテゴリ・商品詳細・買い物かご・フリーページ（ページ別のHTML/CSS/JS入力画面）
- 編集不可/対象外: マイページ・注文画面などmakeshop.jpドメイン側（新マニュアル本文は未検証、**要確認**）。カートページは編集可だが削除禁止タグ多数（OPTION関連・BASKET_ADDCODE1等）で制約大
- レスポンシブ: デザインセット単位でON/OFF可。**ONの1ソース運用を採用**（Phase Cの構成と一致）
- 外部リソース: CSS/JS外部ファイルはギガプラス10へ設置して読込。共通CSS管理→`m_sys_common.css`自動リンク。**Google Fonts利用可**（全フォントの動作保証はサポート外）。JSはシステムと干渉時サポート対象外
- 決済画面: Smart Checkout（1画面型）はUIカスタマイズ（アクセントカラー・ボタン色等）どまり。フルHTML編集は不可

## 4. 無料体験（トライアル）要点

- 期間15日。体験中のデータは本契約後も引き継ぎ
- プレミアムプランのほぼ全機能が利用可の案内（商品上限10,000点 — 45商品は余裕）
- テスト注文: 専用テスト環境はなし。**「任意決済」を設定し実際の購入導線で確認**が公式案内（課金発生なし）
- **要確認**: 体験中のクリエイターモード編集可否の明文（一次情報未発見）／クレカ登録要否／体験限定の商品数上限の有無

1. CSVは新85列フォーマットのテンプレート（実物ダウンロード後に列合わせ）で作成。確定までは**列名・順序を仮置きにしない**（要確認扱い）
