# iroha. MakeShop投入手順書（仮）

このディレクトリは、架空ブランド「iroha.」のポートフォリオデータをMakeShopへ投入するための
データ・テンプレート一式です。**docs/makeshop-notes.md に「要確認」とある事項は未確定のため、
実際の投入作業はCHECKLIST.mdの各項目をPhase Aで実機確認しながら進めてください。**

## ディレクトリ構成

```
makeshop/
  generate-csv.mjs       … products.jsonからCSVを生成するスクリプト（再生成可能）
  convert-images.mjs     … SVGプレースホルダをPNG(800x800)に変換するスクリプト（再生成可能）
  csv/
    products-makeshop.csv       … 商品一括登録CSV（仮フォーマット・UTF-8 BOM付き）
    products-makeshop-sjis.csv  … 同内容（Shift_JIS）
    categories.csv               … カテゴリ一括登録CSV
    README.md                    … 列対応表・要確認事項
  templates/
    top.html / category.html / detail.html … クリエイターモード用テンプレート（Smarty独自タグ入り）
    common.css                              … 共通CSS
  images/
    {SKU}.png × 45 … 商品プレースホルダ画像（800x800）
  CHECKLIST.md … 実機確認チェックリスト（要確認事項の集約）
  README.md     … このファイル
```

## 投入手順

### ① カテゴリ登録
1. `csv/categories.csv` を確認する（5カテゴリ・カテゴリーパス形式）
2. MakeShop管理画面 > 商品管理 > カテゴリ管理 からカテゴリ一括登録のアップロード画面を開く
3. `csv/categories.csv` をアップロードする（文字コードはUTF-8 BOM付き。自動判別対応と調査ノートにあるためそのまま利用可能な想定）
4. 登録後、5カテゴリが管理画面上に正しく反映されているか確認する

> 要確認: カテゴリーパス以外に必須列（表示順・公開設定等）がないか（CHECKLIST.md B-2）

### ② 商品CSVアップロード
1. MakeShop管理画面 > 商品管理 > 商品一覧 > アップロード・ダウンロード から、
   **新85列の正式テンプレートCSVを必ずダウンロードする**（本リポジトリのCSVをそのまま使わない）
2. `csv/README.md` の列対応表を見ながら、`csv/products-makeshop.csv`（または`-sjis.csv`）の
   各列の値を、ダウンロードした正式テンプレートの対応列へ転記する
3. 転記後のCSVをアップロードする
4. 45商品すべてが「カテゴリーパス」で指定したカテゴリに正しく紐付いているか、
   商品名・価格・説明文に文字化けがないかを確認する

> 要確認: 正式テンプレートの文字コード・英語名列の有無・商品説明の列番号・バリエーション区切り文字・
> 拡大画像名の形式（CHECKLIST.md B-1。詳細はcsv/README.md）

### ③ 画像登録
1. `images/{SKU}.png`（45枚・800x800）を、商品登録済みの各商品に対して管理画面からアップロードする
   （①②完了後、SKU＝独自商品コードをキーに商品を特定できる）
2. メイン画像として1枚登録する（詳細ページのサブ画像・一覧用画像をどう扱うかは、
   調査ノート§2の「画像一括登録はURL記載方式」を踏まえ、管理画面の個別アップロードか
   画像一括CSVのどちらで行うかをPhase Aで決定する）
3. 45枚すべてが800x800で正しくアップロードされ、管理画面のプレビューで図形が表示されることを確認する
   （変換手段・検証結果はconvert-images.mjs実行ログ参照。`node convert-images.mjs`で再生成・再検証可能）

> 要確認: SVGがアップロード不可であることの実機確認、画像一括登録を使う場合のURL方式
> （CHECKLIST.md A・B-4）

### ④ バリエーション在庫設定
1. 商品CSVの「バリエーション1名称」列で投入したカラー選択肢に対して、各組み合わせの在庫を設定する
2. 本企画では在庫数は一律10個（デモ用途）。カラー別に個別の10を設定するか、商品単位で10とするかは
   調査ノート§1で「Phase Aで決定」とされている。カラー別にする場合は、別CSV「オプション一括修正」
   (Shift-JIS指定)を使うか、管理画面で個別に設定する
3. 設定後、商品詳細ページでカラーごとに在庫が表示される（または在庫連動する）ことを確認する

> 要確認: バリエーション別在庫10の設定方法がCSVか画面操作か（CHECKLIST.md A）

### ⑤ テンプレート貼付（クリエイターモード）
1. MakeShop管理画面でクリエイターモードを開く（無料体験中に開けるかはCHECKLIST.md A参照。
   開けない場合は本ステップ全体の実施時期に影響するため、/model fable相談の対象）
2. 共通CSSの設定画面に `templates/common.css` の内容を貼り付ける
   （貼り付けると`m_sys_common.css`として自動リンクされる想定。調査ノート§3）
3. トップページの編集画面に `templates/top.html` の `<body>` 内の内容を貼り付ける
   （`<head>`相当の内容を別途どこに設定するかは要確認。CHECKLIST.md B-3）
4. 商品分類（カテゴリ）ページの編集画面に `templates/category.html` を、
   商品詳細ページの編集画面に `templates/detail.html` を同様に貼り付ける
5. 貼り付け後、各テンプレート内のSmarty独自タグ（`{$item.name}`等）が実際に商品データへ
   置換されて表示されるかを、プレビューおよび実際のページ遷移で確認する
   （プレビューは適用前デザインがリンク遷移先に反映されない点に注意。CHECKLIST.md A）
6. テンプレート内の `<!-- TODO要確認: ... -->` コメントを一つずつ確認し、
   正式なタグ名・URL体系が判明次第、該当箇所を置換する（CHECKLIST.md B-3に一覧化済み）

> 要確認事項が最も多いステップ。CHECKLIST.md B-3（15件）を順に潰していくこと

### ⑥ 任意決済でのテスト注文
1. 公式案内に従い「任意決済」を設定する（課金は発生しない。調査ノート§4）
2. 実際の購入導線（カート追加→カート画面→注文画面→決済）を一通り試す
3. カートボタンの挙動（⑤で貼り付けたテンプレートのデモメッセージ、または本番相当の挙動に
   差し替えた場合はその動作）、注文完了までの画面遷移に不自然な点がないかを確認する
4. マイページ・注文画面（Smart CheckoutのUIカスタマイズ範囲）がブランドトーンと
   大きく乖離していないか確認する

> 要確認: テスト注文の完走、マイページ・注文画面のデザイン調整範囲（CHECKLIST.md A）

## 再生成について
`generate-csv.mjs` と `convert-images.mjs` はどちらも`data/products.json`・`site/img/products/`を
読み込むだけの決定論的なスクリプトです（日付・乱数は使用しません）。products.jsonが更新された場合は、

```
node makeshop/generate-csv.mjs
node makeshop/convert-images.mjs
```

を再実行することで、CSV・画像を同じ規則で再生成できます（いずれもスクリプト内で自己検査を行い、
件数・サイズが条件を満たさない場合はエラー終了します）。
