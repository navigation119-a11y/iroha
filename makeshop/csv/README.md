# CSV投入メモ（仮フォーマット → 新85列テンプレートへの転記手順）

このディレクトリのCSVは、MakeShop管理画面からダウンロードする**正式な新85列商品一括登録テンプレート**
（docs/makeshop-notes.md §2参照。2025/12/17以降の新フォーマット）の実物が未取得の段階で、
`generate-csv.mjs` が products.json から機械生成した**仮フォーマット**です。

**実際の投入時は、必ず以下の手順を踏むこと。このCSVをそのままアップロードしない。**

1. MakeShop管理画面 > 商品管理 > 商品一覧 > アップロード・ダウンロード から、新85列の正式テンプレートCSVをダウンロードする
2. 正式テンプレートの列見出し（全角半角・大小文字の完全一致が必要）を確認する
3. 下記「列対応表」を参照し、本ディレクトリのCSVの値を正式テンプレートの対応列へ転記する
4. 文字コード・区切り文字などの要確認事項（下記）をPhase Aで実機確認し、確定後に転記する

## 出力ファイル

| ファイル | 内容 | 文字コード |
|---|---|---|
| `products-makeshop.csv` | 商品一括登録CSV（仮フォーマット・11列・46行=ヘッダ+45商品） | UTF-8 (BOM付き) |
| `products-makeshop-sjis.csv` | 同内容 | Shift_JIS |
| `categories.csv` | カテゴリ一括登録CSV（6行=ヘッダ+5カテゴリ） | UTF-8 (BOM付き) |

新CSVの正式な文字コードは公式マニュアルに明記がなく未確認（docs/makeshop-notes.md §2）のため、
両方の文字コードを用意した。**どちらが正しいかはPhase Aでテンプレートを実際にダウンロードして確認すること。**
Shift_JIS版はmacOS/Linux標準の`iconv`コマンドを`generate-csv.mjs`から呼び出して変換している
（Node標準にはUTF-8からShift_JISへの文字コード変換機能がないため）。

## 商品CSV 列対応表（仮フォーマット → 新85列フォーマットの該当列）

| # | 仮フォーマットの列名 | 値の由来 | 新85列フォーマットでの対応列（調査ノート§2） | 状態 |
|---|---|---|---|---|
| 1 | 商品特定コード指定 | 固定値 `1` | 列1「商品特定コード指定」(必須) | 確認済み |
| 2 | 独自商品コード | `products.json` の `sku` | 列1の指定方式に対応する独自商品コード列 | 確認済み |
| 3 | 商品名 | `products.json` の `nameJa`（そのまま。`nameEn`は含めない） | 列7「商品名」(新規時必須) | **要確認**: 正式テンプレートに英語名専用の別列があるか未確認。無ければ`nameEn`の投入先がない |
| 4 | 販売価格 | `products.json` の `price`（数値のみ） | 列9「販売価格」(新規時必須) | 確認済み |
| 5 | 商品説明 | `products.json` の `description`（そのまま） | 商品説明に該当する列（具体的な列番号は調査ノートに記載なし） | **要確認**: 列番号 |
| 6 | カテゴリーパス | カテゴリの `nameJa`（1階層のみなのでカテゴリ名そのもの） | 列6「カテゴリーパス」（列5のカテゴリー識別コードと二者択一） | 確認済み（パス指定を採用） |
| 7 | バリエーション1名称 | `products.json` の `colors` 配列を `\|` 区切りで連結 | 列32「バリエーション1名称」 | **要確認**: 複数のカラー選択肢を1列に列挙する際の公式区切り文字が調査ノートに記載なし。暫定で`\|`を採用 |
| 8 | 数量 | 固定値 `10` | 列16「数量/在庫」 | 確認済み（商品単位10個とするか、カラー別在庫10にするかはPhase Aで決定。後者の場合は別CSV「オプション一括修正」(S-JIS)で設定） |
| 9 | 商品表示可否 | 固定値 `Y` | 列48「商品表示可否」 | 確認済み |
| 10 | 商品ラベル | `products.json` の `tags` 配列を `\|` 区切りで連結 | 列84「商品ラベル」(最大15件・パイプ区切り) | 確認済み |
| 11 | 拡大画像名 | `{SKU}.png`（`convert-images.mjs`の出力ファイル名と一致） | 列36-38付近「画像名」 | **要確認**: 画像一括登録は「ギガプラス10へ先にアップロードしURLを記載」する方式との記載があり（調査ノート§2）、ファイル名だけで良いのか、URL形式が必要なのか未確認 |

### このCSVに含まれない列について
新85列フォーマットの残り列（JAN・送料区分・バリエーション2名称・SEO関連など）は、
今回の企画要件（45商品・5カテゴリ・カラー展開・数量10・タグ）に含まれないため、仮フォーマットには入れていない。
正式テンプレートへ転記する際、新規登録に必須な列（商品名・販売価格以外）が他にもないか、
ダウンロードしたテンプレートの入力規則シートを確認すること。

## カテゴリCSV列対応表

| 列名 | 値の由来 | 状態 |
|---|---|---|
| カテゴリーパス | カテゴリの `nameJa`（`ノート・紙もの`等） | 確認済み（パス指定形式） |

公式の「カテゴリ一括登録」CSVに、カテゴリーパス以外の列（表示順・公開設定・SEO設定・アイコン画像等）が
必須として存在するかどうかは調査ノートに記載がない。**要確認**: Phase Aで実テンプレートをダウンロードし確認すること。
文字コードはShift-JIS/UTF-8自動判別との記載があるため(調査ノート§2)、UTF-8 (BOM付き) 1本のみを用意した。

## 複数カテゴリ所属・在庫別設定について
- 1商品を複数カテゴリに所属させたい場合、新規登録CSVでは1商品1カテゴリのみのため、
  別CSV「商品のカテゴリー一括登録・解除」(Shift-JIS指定)を別途使う必要がある（調査ノート§2）。本企画では1商品1カテゴリ運用のため未使用。
- カラー別（バリエーション組合せ別）に在庫10を個別設定したい場合は、別CSV「オプション一括修正」(Shift-JIS指定)
  または管理画面での個別設定が必要（調査ノート§1・§2）。本CSVの「数量」列は商品単位の在庫として暫定投入している。

## 要確認事項サマリ（このREADME内の件数）
上表中「要確認」と明記した項目は計4件（商品名の英語名列・商品説明の列番号・バリエーション区切り文字・拡大画像名のURL形式要否）＋
カテゴリCSVの追加列要否1件 = **合計5件**。CHECKLIST.mdにも転記している。
