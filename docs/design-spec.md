# iroha. デザインシステム＆ページ仕様

> 企画書§2〜§4・§7を具体化した実装仕様。builderはこの仕様に従って量産する。
> デザイン軸: **「大人っぽさもあるポップ」** — 余白と端正なタイポで"大人"を、色と幾何学図形で"ポップ"を作る。色で遊び、文字では遊ばない。

---

## 1. デザイントークン（CSSカスタムプロパティ）

```css
:root {
  /* ブランドカラー（企画書§3） */
  --c-blue:   #315BCB;  /* IROHA BLUE: 基調・リンク・見出し */
  --c-orange: #F07842;  /* VIVID ORANGE: CTA・ロゴドット専用のアクセント */
  --c-yellow: #F3C94B;  /* SUNNY YELLOW */
  --c-pink:   #E66B88;  /* PLAYFUL PINK */
  --c-green:  #68A58D;  /* FRESH GREEN */
  --c-offwhite: #F7F5EF; /* 背景 */
  --c-ink:    #292929;  /* 本文 */

  /* 派生（淡色面・罫線） */
  --c-paper: #FFFFFF;
  --c-line: rgba(41, 41, 41, 0.12);
  --c-ink-soft: rgba(41, 41, 41, 0.64);
  /* カテゴリ淡色背景は color-mix(in srgb, var(--cat) 12%, white) で統一 */

  /* タイポグラフィ */
  --font-en: "Poppins", sans-serif;
  --font-ja: "Noto Sans JP", sans-serif;

  /* スペーシング: 8px基準 */
  --sp-1: 8px;  --sp-2: 16px; --sp-3: 24px; --sp-4: 32px;
  --sp-6: 48px; --sp-8: 64px; --sp-10: 80px;

  /* 角丸: 丸すぎると幼くなるため控えめ＋ボタンのみピル */
  --r-card: 12px; --r-img: 8px; --r-pill: 999px;

  /* 影: 原則使わない（企画書「過剰な影」回避）。浮きが必要な場合のみ */
  --shadow-soft: 0 2px 12px rgba(41, 41, 41, 0.06);

  --w-content: 1200px;   /* コンテンツ最大幅 */
}
```

### 色の運用ルール
- 画面の約60%はオフホワイト/白。1画面の主役色は2〜3色まで（企画書§3）
- **VIVID ORANGEはCTA（カートに入れる・商品を見る）とロゴドットにほぼ専有させる**。装飾に乱用しない
- **CTA（オレンジ地）の文字はink**（白文字×オレンジは2.81:1でAA未達のため禁止。彩色地にはink文字・ink地には白文字、を全体ルールとする）
- IROHA BLUEは見出し・リンク・ヘッダーの構造色。ベタ面で使うのはヒーロー/カテゴリバンドなど1画面1箇所まで
- 黄・桃・緑はカテゴリ色／タグ／図形アクセントとしてのみ登場

### カテゴリカラー（サイト全体の構造原理）
5カテゴリに1色ずつ割り当て、一覧ヘッダ・カテゴリカード・プレースホルダ画像・パンくず等で一貫させる。

| slug | カテゴリ | 色 |
|---|---|---|
| `notebook-paper` | NOTEBOOK & PAPER | IROHA BLUE `#315BCB` |
| `pen-writing` | PEN & WRITING | VIVID ORANGE `#F07842` |
| `sticker-craft` | STICKER & CRAFT | SUNNY YELLOW `#F3C94B` |
| `desk-accessories` | DESK ACCESSORIES | FRESH GREEN `#68A58D` |
| `gift-set` | GIFT & SET | PLAYFUL PINK `#E66B88` |

※ カテゴリページではオレンジCTAと主役色が重なるため、`pen-writing` ページ内のCTAはIROHA BLUEに切り替えてよい（1画面2〜3色ルール優先）。

## 3. グラフィック要素

- 使用図形: 円・半円・角丸四角・波形（企画書§3）。**輪郭線は使わずフラット塗り**。グラデ・立体禁止
- 役割を持たせる: セクション区切りの波形、カテゴリアイコン、リストマーカー。無意味な散らし置きはSP時に削る
- **ステッカー風タグチップ**: 商品タグ（定番/人気/おすすめ/主力/ギフト/限定）は「シールを貼った」見た目で表現
  - 形: ピル型。**カテゴリ色12%淡色地＋ink文字**＋カテゴリ色1px枠（白地＋カテゴリ色文字はyellow等でAA未達のため禁止）
  - `限定` のみ ink地＋白文字で特別感を出す
- ロゴ: `iroha.` Poppins SemiBold、文字=blue・ドット=orange、下に `STATIONERY & CREATIVE GOODS`（Poppins 500 / 9px / letter-spacing 0.2em / ink-soft）。SVGでHTML内に直書き（画像化しない）

## 4. プレースホルダ画像システム（Phase C）

実写・生成画像の代わりに、**カテゴリ色の幾何学コンポジションSVG**を機械生成する。ダミーに見えず「ブランドのグラフィック」として成立させる。

- 生成: `site/build.mjs` 内でSKUごとに決定論的に生成（乱数は使わずSKU連番から配置パターンを決める）
- 仕様
  - 比率1:1（一覧・詳細共通）。詳細サブ画像は同システムの配置違い3点
  - 背景: カテゴリ色12%淡色
  - モチーフ: カテゴリごとの商品アーキタイプ図形＋小図形1〜2個
    - notebook-paper: 角丸長方形（表紙）＋背表紙帯
    - pen-writing: 斜めのカプセル形（ペン軸）＋ペン先三角
    - sticker-craft: 大小の円・四角の散らし
    - desk-accessories: 積み重なるブロック面
    - gift-set: 四角（箱）＋半円（リボン）
  - 配色: カテゴリ色＋白＋補助1色（商品のカラー欄の先頭色をブランドパレットにマップ: ブルー系→blue / オレンジ・コーラル・テラコッタ→orange / イエロー→yellow / ピンク→pink / グリーン・セージ→green / その他→ink12%）
  - **文字・ロゴは一切描き込まない**（企画書§1）
- メインビジュアル: オフホワイト地＋大型図形クラスタ（HTML/CSSで構成）。コピーはHTMLテキスト
- 将来差し替え: `site/img/products/{SKU}/main.svg` 等のパス規約を固定し、実画像(`{SKU}/main.webp`)に差し替えてもテンプレ変更不要とする

## 5. 共通レイアウト

### ポートフォリオ注記バー（全ページ最上部・必須）
- ink地・白文字11px・中央揃え:「本サイトは架空ブランド「iroha.」のポートフォリオ作品です。実際の販売・購入はできません。」
- フッター末尾にも同文を再掲（企画書§10）

### ヘッダー（白地・下線1px・sticky）
- PC: 左=ロゴ ／ 中央=ナビ（CATEGORY▾ / ABOUT / GIFT GUIDE / NEWS / FAQ）／ 右=検索・カートアイコン
- CATEGORY▾ は5カテゴリ＋ALL ITEMSのドロップダウン（カテゴリ色ドット付き）
- SP: 左=ロゴ／右=検索・カート・ハンバーガー。メニューは全面オーバーレイ（オフホワイト地、EN大見出し流用）

### フッター（オフホワイト地）
- 4列（SP: アコーディオンまたは縦積み）: SHOP（5カテゴリ+ALL）／ GUIDE（ABOUT・GIFT GUIDE・FAQ・NEWS）／ POLICY（ご利用ガイド・特商法※デモ注記・プライバシーポリシー）／ ロゴ+SNSアイコン
- 最下段: `© iroha.` ＋ポートフォリオ注記再掲

### ブレークポイント
- SP基準（〜767px）→ `min-width: 768px` でタブレット/PC、`min-width: 1024px` でフルレイアウト
- 商品グリッド: SP 2列 / 768px〜 3列 / 1024px〜 4列。gap: SP 12px / PC 24px

### 6-2. 商品一覧（ALL ITEMS ＋ カテゴリ×5）
- パンくず: TOP > CATEGORY名
- カテゴリヘッダ: カテゴリ色12%地の全幅バンド。EN名大タイポ（ink。カテゴリ色はバンド背景＋見出し下のカラーバー等のアクセントで表現。カテゴリ色文字はorange/yellow/greenでコントラスト未達のため不使用）＋JA名＋説明1行＋商品数
- ツールバー: 件数表示／タグ絞り込みチップ（定番・人気・おすすめ・主力・ギフト・限定、JSでクライアント絞り込み）／並び順（おすすめ=SKU順・価格昇降、JS実装）※MakeShop移植時は標準機能に置換（要確認）
- 商品カード: 画像1:1（hoverでサブ画像に切替）→タグチップ（画像左上に重ねる）→JA名→EN名→価格。カード全体がリンク
- ALL ITEMSはカテゴリ見出し付きで5ブロック連結ではなく、全45商品を1グリッド＋カテゴリ絞り込みチップで表示

### 6-3. 商品詳細（×45）
- パンくず: TOP > カテゴリ > 商品名
- 2カラム（SP縦積み）:
  - 左: メイン画像＋サブサムネ3点（クリック切替）
  - 右: カテゴリラベル（色ドット＋EN名リンク）→ JA商品名(H1)＋EN名 → タグチップ → 価格(税込) → 商品説明 → カラー選択UI（選択肢をピルで表示。デモとして選択可・在庫連動なし）→ 仕様テーブル（カラー/仕様/SKU）→ 数量±UI → 「カートに入れる」(orangeピル・全幅)
  - カートボタン押下時: alertではなくボタン下にインラインメッセージ「※ポートフォリオ作品のため購入はできません」を表示
  - `ギフト`タグ商品のみ: pink淡色のギフト提案ボックス「ラッピングを想定したギフト向けアイテムです。GIFT GUIDE →」
- 関連商品: 同カテゴリから4点（自身を除くSKU順、末尾は先頭へ循環）
- セット商品（GS系・PW010等）: 仕様欄のセット内容をリスト表示

### 6-4. ABOUT
- ヒーロー: コンセプトコピー大組み＋図形

### 6-5. GIFT GUIDE

### 6-6. NEWS / FAQ（スタブ）
- NEWS: 一覧のみ（デモ3件、詳細ページなし）

## 7. アクセシビリティ・品質基準

- テキストコントラスト: 本文はink/白系地で確保。カテゴリ色の上に本文を載せない（yellowの上の白文字は禁止。yellow地では文字はink）
- 画像altは商品名を設定（プレースホルダ段階から）
- フォーカスリング: blue 2px。hover変化は色・下線・画像切替のみ（過剰アニメ不可）
- 禁止事項の再確認: 原色の全面敷き詰め／丸文字／キャラクター／過剰な影・グラデ／余白のない詰め込み（企画書§3）

## 8. MakeShop移植を見据えた実装規約（Phase C時点から適用）

- 商品カード・価格・商品名などのHTML構造は「MakeShop独自タグに置換しやすい」ようフラットに保つ（深いネスト・擬似要素依存のレイアウトを避ける）
- CSSは1ファイル（`site/css/style.css`）。セレクタは `.p-` プレフィックスのクラスのみ（IDセレクタ・タグ直指定を避け、MakeShop既存CSSとの衝突リスクを下げる）
- JS依存を最小化（メニュー・絞り込み・画像切替・カートデモの4点のみ）。MakeShop側で使えない場合に落としても成立するプログレッシブ・エンハンスメント構成
- 検索・カート・購入フローはMakeShop標準機能を使う前提とし、静的版ではUIのみ設置（要確認リスト対象）
